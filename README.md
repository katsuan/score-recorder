# スコア録画（仮）

スマホで試合を撮りながら、得点板（チーム名とスコア）を動画にそのまま入れて残すツール。さくせん盤（SAQSEN）の追加アプリ。名前・ロゴはこれから決める。

## できること

- チーム名・色を入れて「📹 カメラを開く」。さくせん盤で入れたチーム名・色があれば、それを使う（同じ katsuan.github.io の localStorage `soccer:state`）
- 撮る画面はスマホを横向きで使う。左下が自チーム、右下が相手の「＋1」（下の小さな「−1」で取り消し）。真ん中の赤い丸で録画の開始・停止
- 得点板は映像の左上に「[色] 自チーム 2 - 1 相手 [色]」。時間は入れない（動画の時間を見る）
- 止めると見返し・保存（iPhone などは共有メニューから「ビデオを保存」、それ以外はダウンロード）。動画はこの端末にだけ残り、サーバーには送らない
- スコアは端末に残る（`scorecam:state`）。はじめの画面で「0 - 0 にする」

## しくみ

カメラの映像と得点板を1つのキャンバスに描き、そのキャンバス（＋マイクの音）を MediaRecorder で録る。ボタンはキャンバスの上に重ねた別の部品なので、動画には入らない。録れる形式は端末による（iPhone は mp4、Android・パソコンは webm のことが多い）。撮っている間は画面を消さない（Wake Lock）。

注意：録画中に画面を消したり別のアプリに切りかえたりすると、映像が止まる。長く撮ると発熱・電池の消耗が大きいので、前半・後半で分けて撮るのがよい。

## ローカルでの確認

```bash
python3 -m http.server 8799
```

カメラは https か localhost でしか使えない。
