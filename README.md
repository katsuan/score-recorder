# ろくが（RoQga）

試合の動画に、得点板（チーム名とスコア）をそのまま入れて残すツール。名前は「録画」の「く」を Q にした、コネクト〜ConneQt〜の仲間（さくせん盤の追加アプリ）。キャッチコピーは「撮った試合も、取った点も、とっておき」。

公開URL: https://katsuan.github.io/score-recorder/

## 使い方は2つ（はじめの画面の上のタブ）

チーム名・色・プレビュー・スコアは2つで共通。

### 📹 撮る

1. チーム名・色を入れて「📹 カメラを開く」（画面の下に固定。スクロールしなくても押せる）
2. スマホを横にして、赤い丸で録画の開始・停止（タップ）
3. 点が入ったら、そのチームの色の「＋1」。押しまちがいは小さな「−1」
4. おしい場面・いいプレーは「⭐ ナイス」（点は変えずに、ハイライトに入れる。録画前から出ていて、効くのは録画中）

### 🎞 あとから付ける

1. 「🎞 動画を選ぶ」で、撮っておいた動画を選ぶ（動画が途中からなら、先に「✏️ スコアを変える」で、はじめのスコアを入れておく）
2. 動画を流しながら、点が入ったところでチームの色の ＋1（−1・⭐ ナイスプレーも）。一覧の時間を押すとその少し前へ、✕ で消す
3. 「📼 得点板つきで書き出す」：範囲は「全部」か「⚡ ハイライト」。ボタンに、かかる時間の目安

## ⚡ ハイライト

得点と ⭐ ナイスプレーの、10秒前〜6秒後をつないで1本にする（近いものはひとつにまとめる）。短いので LINE でも送りやすい。

- 撮るとき：撮っているあいだに ＋1・⭐ を押した時間を覚えておく（−1 はそのチームのいちばん新しい得点を取り消す。⭐ は消さない）。止めたあと、保存の画面の「⚡ 得点ハイライトを作る（約 ◯:◯◯）」で、録った動画（5分ごとに分かれていてもまたいで）から切り出す。得点板はもう入っているので描きなおさない
- あとから付けるとき：書き出す範囲を「⚡ ハイライト」に
- どちらも、できた動画は保存の画面に「⚡ ハイライト」として並ぶ

## 保存の画面（録画を止めたあと・書き出したあと）

- 見返し・保存・共有。iPhone は「📤 保存・共有」→「ビデオを保存」で写真へ、共有できない端末は ⬇️。共有は動画だけ（題名や文字はつけない。LINE で別のメッセージにならないように）
- LINE で送れる動画は5分まで：いつも5分（4分55秒）ごとに自動で次の1本に分けて録る。5分を超えたときだけ「全部・最初の5分・最後の5分」から残すものを選べる（確かめるときは ?segment=秒 で区切りを短くできる）
- 「次はどうする？」：「▶ 続きを撮る」（同じチーム・いまのスコアのまま。後半など）／「⟲ 同じチームで 0 - 0 から」（次の試合）／「🏠 はじめの画面へ」（チーム・色を変える）。共有がすむと「✓ 共有できました」と出て、0 - 0 からが目立つ
- 動画は、どれを選んでも消えない。「1回目・2回目…」と並び、保存・共有したものには ✓。消すのは 🗑（まだ保存していないものだけ確かめる）。はじめの画面からも「🎞 録った動画（◯本）」で開ける
- 動画はこの端末の中だけ（サーバーには送らない）。ページを閉じる・更新すると消える

## はじめの画面

- チーム：「左のチーム・右のチーム」と呼ぶ（自分のチームの試合とはかぎらないので）。あいだの「⇄」で左右を入れかえる（後半にコートが変わったときなど。得点板・撮る画面の ＋1・GOAL のエフェクトの並びもそろって入れかわる）
- チームの色：緑・黄・白の丸いボタンと、カスタム（自由な色）。さくせん盤と同じ形。もう片方のチームと同じ色も選べるが、薄く出す
- チーム名・色は、さくせん盤と共通（同じ katsuan.github.io の `soccer:state` の team・opponent・ourColor・oppColor）。左のチーム＝さくせん盤の自チーム、右のチーム＝相手。どちらで変えても、もう一方にも出る。さくせん盤にまだなければ、ろくがで前に使ったもの → 緑・白
- いまのスコアはチーム名のあいだ。「✏️ スコアを変える」で − ＋、点があるときは「0 - 0 にする」
- 「👀 プレビュー・GOAL のエフェクト」（たたんだ欄）：動画に入る得点板の見本と、GOAL のエフェクト（＋1 のとき、得点したチームの色の帯と「⚽ GOAL!」を2秒ほど。動画にも入る。ふだんは出さない。出すときは見出しに ON）

## 撮る画面

- 得点板は映像の左上に「[色] 左のチーム 2 - 1 右のチーム [色]」（チーム名がないときは色の丸）。時間は入れない（動画の時間を見る）
- ＋1 はチームの色のボタン（字は色の明るさで白か黒）。押すとボタンが一瞬光る（Android は軽く震える）。画面のまんなかには何も出さない（動画に入るのか迷わせないため）
- ＋1 の位置：右上の小さな丸（3つの点）で まんなか → 左よせ → 右よせ。まんなかは録画ボタンのすぐ左右（画面の長さがちがっても同じ場所）。寄せると ＋1 が持つ側のはしに縦2段（上が得点板の左のチーム）、録画ボタンは反対側のはしへ（親指が当たらないように）。録画中も切りかえられる
- 右上：🏠（はじめの画面へ）・⇅（倒して撮るときだけ。倒す向きを逆に）・＋1 の位置。録画中は ＋1 の位置だけ残す
- 録画中は画面のふちが赤く光り、上のまんなかに時間（動画には入らない）
- 画面の回転をオフにしていても撮れる：縦の画面のときは「左に倒す／右に倒す」（スマホの絵が倒れるアニメーションつき）で、撮る画面ごと 90° 回り、映像も横に回して描く。どちらに倒してもボタンの並びは同じ。選んだ向きは端末に覚え、次から縦の画面で開いたときは選ばずにその向きで始まる（ちがえば ⇅）。録画中は向きを変えない

## しくみ

映像と得点板を1つのキャンバスに描き、そのキャンバス（＋音）を MediaRecorder で録る。ボタンはキャンバスの上に重ねた別の部品なので、動画には入らない。録れる形式は端末による（iPhone は mp4、Android・パソコンは webm のことが多い）。撮っている間は画面を消さない（Wake Lock）。

- あとから付ける・ハイライトの書き出しは、動画を流しながら録るので、流した時間だけかかる（速さはいつも 1×。あいだを飛ばすところは録画を一時停止してつなぐ）。音は Web Audio で取り出す（iPhone のマナーモードでも聞こえるよう audioSession を playback に）
- 長さの入っていない webm（Android のろくがの動画など）は、いちど最後まで飛ばして長さを調べてから使う

注意：録画・書き出し中に画面を消したり別のアプリに切りかえたりすると、映像が止まる。長く撮ると発熱・電池の消耗が大きいので、前半・後半で分けて撮るのがよい。

## ファイル

- index.html・style.css：画面
- js/：動き（役ごとのファイル。index.html の順に読む。いちばん先の core.js の頭に、ファイルの一覧）
  - core.js 共通の道具と state ／ draw.js 得点板・GOAL のエフェクトを描く ／ setup.js はじめの画面 ／ studio.js 撮る画面
  - record.js 録画と保存の画面 ／ editor.js あとから付ける ／ render.js 書き出し・⚡ ハイライト ／ main.js 最初の表示（全部読んでから）
- tools/icon.py：アイコン・ロゴ・OGP（おくるんの tools/brandkit.py を使う。さくせん盤と同じピッチの緑に、Q はカメラのレンズの輪と録画中の赤いランプ）。tools/logo_ro.py：横ロゴの「Ro」（R の足が o のボールを蹴る）
- 公開前に `python3 ../q-oqrn/tools/qstamp.py index.html`（読み込む CSS・JS に版の番号）
- おくるんの一覧（line-share の data/hub-links.json の `key: "roqga"`）に載っている。はじめの画面のいちばん下に「📤 ろくがを紹介する」と仲間のアイコン列（line-share の shared/tool-share.js）
