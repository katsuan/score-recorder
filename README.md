# ろくが（RoQga）

試合の動画に、得点板（チーム名とスコア）をそのまま入れて残すツール。名前は「録画」の「く」を Q にした、コネクト〜ConneQt〜の仲間（さくせん盤の追加アプリ）。キャッチコピーは「撮った試合も、取った点も、とっておき」。

公開URL: https://katsuan.github.io/score-recorder/


はじめの画面の部品（見出しの行・使い方のタブ・チーム名の入力欄・プレビューの開閉・ボタン）は、おくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`。使い方はおくるんの README）。色と字は `style.css` の `:root`（`--ls-accent` など。ろくがの緑）。チームの色の丸と選べる色（チーム名の枠の中の丸と、その下の8色＋カスタムの1行。さくせん盤・アプリ版と同じ形）・エフェクトの小さなチップ・撮る画面・保存の画面は、ろくがにしかない見た目なので `style.css` のまま。
## 使い方は2つ（はじめの画面の上のタブ）

チーム名・色・プレビュー・スコアは2つで共通。

### 📹 撮る

1. チーム名・色を入れて「📹 カメラを開く」（画面の下に固定。スクロールしなくても押せる）
2. スマホを横にして、赤い丸で録画の開始・停止（タップ）
3. 点が入ったら、そのチームの色の「＋1」。押しまちがいは小さな「−1」
4. おしい場面・いいプレーは「⭐ ナイス」（点は変えずに、ハイライトに入れる。録画前から出ていて、効くのは録画中）

### 🎞 撮った動画に（得点板をつける）

1. 「🎞 動画を選ぶ」で、撮っておいた動画を選ぶ（動画が途中からなら、先に「✏️ スコアを変える」で、はじめのスコアを入れておく）
2. 動画を流しながら、点が入ったところでチームの色の ＋1（−1・⭐ ナイスプレーも）。一覧の時間を押すとその少し前へ、✕ で消す（すぐ消し、「元に戻す」で戻せる）
3. 「📼 得点板つきで書き出す」：範囲は「全部」か「⚡ ハイライト」。ボタンに、かかる時間の目安

## ⚡ ハイライト

得点と ⭐ ナイスプレーの、10秒前〜6秒後（はじめの値。はじめの画面の「💾 保存の設定」・保存の画面・撮った動画にで 1〜30 秒に変えられる）をつないで1本にする（近いものはひとつにまとめる）。短いので LINE でも送りやすい。

- 撮るとき：撮っているあいだに ＋1・⭐ を押した時間を覚えておく（−1 はそのチームのいちばん新しい得点をなかったことにする。⭐ は消さない）。止めたあと、保存の画面の「⚡ 得点ハイライトを作る（約 ◯:◯◯）」で、録った動画（5分ごとに分かれていてもまたいで）から切り出す。得点板はもう入っているので描きなおさない
- 撮った動画に（得点板をつける）とき：書き出す範囲を「⚡ ハイライト」に
- どちらも、できた動画は保存の画面に「⚡ ハイライト」として並ぶ

## 保存の画面（録画を止めたあと・書き出したあと）

- 横の画面では、左に見返し・右に保存や次の行き先（右の欄だけ動く）。右は、保存・共有 → ⚡ ハイライト → 次はどうする？ の順
- 見返し・保存・共有。iPhone は「📤 保存・共有」→「ビデオを保存」で写真へ、共有できない端末は ⬇️。共有は動画だけ（題名や文字はつけない。LINE で別のメッセージにならないように）
- 結果の札：動画の最初か最後に 2 秒、RoQga の面にチーム名と最後のスコア（最初にすると LINE などのサムネに結果が出る）。「💾 保存の設定」で なし／最初／最後 と、ハイライトだけ／全部にも（はじめは最初・ハイライトだけ）。撮りながらの全部は、撮りはじめに結果が分からないので最後に入れる（止めるボタンのあと 2 秒録ってから止まる）。得点板を出さないときは入れない
- 🔗 つなぐ：ハイライトなど、いくつかの動画を選んで1本につなぐ（撮った順に並び、↑↓ で並べかえ・✕ で外す。つなぎ目の柄）。5分をこえたら：途中で切らない（4分55秒に収まるところまで動画を詰め、動画の途中では切らない。1本で5分をこえる動画だけ時間で切る）／5分ごとに切る／分けない。ファイル名は「名前_日付_part1」。つなぎ目の柄・分けた各1本の最初の「1/3」の札は、ハイライトとは別に選ぶ（はじめは どちらも入れない）。
  - 5分をこえて切るところは、作り直さずに切れるキーフレーム（iPhone の動画ならほぼ1秒ごと）にそろえる（4分55秒より少し短くなる）
  - 柄・札なしで、mp4 の形式（コーデック・大きさ・向き・音）がそろっていれば、作り直さずに並べる（5分ごとに切る・5分をこえる動画を切るときも）（js/quickjoin.js：目次だけ読み、コマの表を足して新しい目次を作る。データは File の切り出しのまま。外の部品なし）。すぐ終わり、画質もそのまま。できた長さが合わなければ流してつなぐ
  - 柄・札を入れる・形式がちがう（webm など）・キーフレームで切れないときは、流しながら録るので、つないだ長さぶんかかる（30分をこえるときはアプリをすすめる）
- 撮った動画に：動画を選んだら、点の入れ方を2つから選ぶ（ちがいを ✓・✕ と長さの目安で出す）。「▶ 見ながら記録」は 1× で1回流しながら同時に書き出す（見終わったら完成。一時停止はできる・速さ・戻しはなし。終わったら保存の画面から ⚡ 得点ハイライト・LINE で送る用も作れる）。「✏️ じっくり記録」はいまの形（速さ・10秒戻し・一覧で直す。書き出しでもう1回流す）。見出しのよこに、いまの記録のしかた
- 録画は、はじめは止めるまで1本。はじめの画面の「💾 保存の設定」で「5分ごとに分ける」にすると、LINE のトークで送れるよう5分（4分55秒）ごとに次の1本に分けて録る。分けて5分を超えたときだけ「全部・最初の5分・最後の5分」から残すものを選べる（確かめるときは ?segment=秒 で区切りを短くできる）
- 保存の画面は、何本かあるとき「📤 まとめて保存・共有」をいちばん上に（LINE の中のブラウザでは、1本保存するとページが開きなおされて残りが消えることがあるため）。LINE の中で開いたときは、はじめの画面に「Safari・Chrome で開く」（openExternalBrowser=1）
- 「次はどうする？」：「▶ 続きを撮る」（同じチーム・いまのスコアのまま。後半など）／「⟲ 同じチームで 0 - 0 から」（次の試合）／「🏠 はじめの画面へ」（チーム・色を変える）。共有がすむと「✓ 共有できました」と出て、0 - 0 からが目立つ
- 動画は、どれを選んでも消えない。「1回目・2回目…」と並び、保存・共有したものには ✓。消すのは 🗑（確かめずにすぐ消し、トーストの「元に戻す」で戻せる）。はじめの画面からも「🎞 録った動画（◯本）」で開ける
- 動画はこの端末の中だけ（サーバーには送らない）。ページを閉じる・更新すると消える
- 利用状況の記録：おくるんと同じしくみ（Q キットの `shared/log.js` → おくるんの GAS → スプレッドシート「おくるん 利用状況」。道具の名前は `score-recorder`）。開いた（open）とエラーは log.js がひとりでに、使ったことは `js/page.js` の `logUse` が「send」に種類（kind）をつけて送る：`camera`（📹 カメラを開けた）・`pick-video`（🎞 動画を選んだ）・`shot`（録った。数は秒）・`export`／`highlight`（書き出し終えた。数は秒）・`share`（共有した。数は本数）。動画・チーム名・スコアは送らない。電波がないとき・部品が読めないときは送らずにそのまま使える。手元（localhost）では送らない

## はじめの画面

- チーム：「左のチーム・右のチーム」と呼ぶ（自分のチームの試合とはかぎらないので）。あいだの「⇄」で左右を入れかえる（後半にコートが変わったときなど。得点板・撮る画面の ＋1・GOAL のエフェクトの並びもそろって入れかわる）
- チームの色：緑・黄・白の丸いボタンと、カスタム（自由な色）。さくせん盤と同じ形。もう片方のチームと同じ色も選べるが、少し薄くして斜めの線（白でも分かる）
- チーム名・色は、さくせん盤と共通（同じ katsuan.github.io の `soccer:state` の team・opponent・ourColor・oppColor）。左のチーム＝さくせん盤の自チーム、右のチーム＝相手。どちらで変えても、もう一方にも出る。さくせん盤にまだなければ、ろくがで前に使ったもの → 緑・白
- いまのスコアはチーム名のあいだ。「✏️ スコアを変える」で − ＋、点があるときは「0 - 0 にする」
- 「👀 プレビュー・得点板と演出」（たたんだ欄）：動画に入る得点板の見本と、得点のエフェクト（＋1 のとき、得点したチームの色の帯と「⚽ GOAL!」を2秒ほど。動画にも入る。はじめは出す（見出しに ON）。「出さない」にもできる）
  - アイコン（⚽ 🏀 ⚾ 🏐 🏉 🎾 🏸・カスタム（好きな絵文字・文字を2文字まで）・なし）と文字（12字まで。空なら GOAL!）を変えられる。サッカー以外でも使える。長い文字は横からはみ出さないよう縮める。欄は1行（[いまのアイコン][文字]）で、アイコンを押すと下に選べるアイコンが並ぶ（カスタム・なしも）。エフェクトを出さないときは、アイコンと文字の欄も出さない

## 撮る画面

- 得点板は映像の左上に「[色] 左のチーム 2 - 1 右のチーム [色]」（チーム名がないときは色の丸）。時間は入れない（動画の時間を見る）
- ＋1 はチームの色のボタン（字は色の明るさで白か黒）。押すとボタンが一瞬光る（Android は軽く震える）。画面のまんなかには何も出さない（動画に入るのか迷わせないため）
- ＋1 の位置：右上の小さな丸（3つの点）で まんなか → 左よせ → 右よせ。まんなかは録画ボタンのすぐ左右（画面の長さがちがっても同じ場所）。寄せると ＋1 が持つ側のはしに縦2段（上が得点板の左のチーム）、録画ボタンは反対側のはしへ（親指が当たらないように）。録画中も切りかえられる
- はじめて開いたときだけ、はじめの画面に使い方を3つ（Q キットの firstTip。チーム名と色・📹 撮りながら・🎞 撮った動画に）
- はじめて撮る画面を開いたときだけ「はじめての方へ」（赤い丸・＋1・⭐ ナイス・●●● の使い方。「わかった」で、この端末では次から出さない。縦の画面で「横向きにしてください」が出ているあいだは出さない）
- 左よせ・右よせ（縦2段）のときは、＋1 の上に小さくチーム名
- 右上：🏠（はじめの画面へ）・⇅（倒して撮るときだけ。倒す向きを逆に）・＋1 の位置。録画中は ＋1 の位置だけ残す
- 録画中は画面のふちが赤く光り、上のまんなかに時間（動画には入らない）
- 画面の回転をオフにしていても撮れる：縦の画面のときは「左に倒す／右に倒す」（スマホの絵が倒れるアニメーションつき。横にできないときは、この画面の「🏠 はじめの画面へ」でもどれる）で、撮る画面ごと 90° 回り、映像も横に回して描く。どちらに倒してもボタンの並びは同じ。選んだ向きは端末に覚え、次から縦の画面で開いたときは選ばずにその向きで始まる（ちがえば ⇅）。録画中は向きを変えない

## しくみ

映像と得点板を1つのキャンバスに描き、そのキャンバス（＋音）を MediaRecorder で録る。ボタンはキャンバスの上に重ねた別の部品なので、動画には入らない。録れる形式は端末による（iPhone は mp4、Android・パソコンは webm のことが多い）。撮っている間は画面を消さない（Wake Lock）。

- 撮った動画に（得点板をつける）・ハイライトの書き出しは、動画を流しながら録るので、流した時間だけかかる（速さはいつも 1×。あいだを飛ばすところは録画を一時停止してつなぐ）。音は Web Audio で取り出す（iPhone のマナーモードでも聞こえるよう audioSession を playback に）
- 長さの入っていない webm（Android のろくがの動画など）は、いちど最後まで飛ばして長さを調べてから使う

注意：録画・書き出し中に画面を消したり別のアプリに切りかえたりすると、映像が止まる。長く撮ると発熱・電池の消耗が大きいので、前半・後半で分けて撮るのがよい。

## ⚡ ハイライトのつなぎ目

切り出した部分が2つ以上あるとき、つなぎ目の前後 0.4 秒ずつ（合わせて 0.8 秒）に柄を重ねる（前の部分の終わりで入ってきて画面をおおい、次の部分のはじめで抜ける。動画の長さは変わらない）。柄は「撮った動画に」で ⚡ ハイライトを選んだとき・保存の画面の「⚡ 得点ハイライトを作る」の上で選ぶ（端末に覚える）。

- 「撮った動画に」の書き出しは「何を書き出す？」を2つから選ぶ：📼 全部／⚡ ハイライト（得点・⭐ の前後だけ）。それぞれ長さの目安つき。ハイライトは ＋1 か ⭐ を入れると選べる。つなぎ目はハイライトのときだけ出す
- 得点板を出すか（出す／出さない）は「👀 プレビュー・得点板と演出」の欄（撮った動画にでは「🎉 得点板と演出」）で選ぶ。プレビュー・撮る画面・撮った動画に・書き出す動画のすべてに効く（出さないときは GOAL の演出・⭐ の場面・つなぎ目だけ。撮りながら GOAL・ナイスだけを残すこともできる。GOAL の演出もチームを区別しない：帯はつなぎ目の柄と同じ芝の緑（#1f6b38）で、下のチーム名・スコアも出さない（▶ 試すのときは「（お試し）」だけ）。＋1 もチームを分けない1つの「GOAL」ボタン（芝の緑。撮る画面・撮った動画にの両方。左のチームの点として覚える。入れた点の一覧も「GOAL」だけ））。端末に覚える
- 柄の一覧は `js/draw.js` の `TRANSITIONS`（いまは RoQga・なし）。`premium: true` の柄は有料プラン用で、🔒 つきで出して選べないようにする。柄を足す・差しかえるときは、一覧に1行と描き方を足す
- RoQga：濃い緑のピッチの面（左右の辺が斜め。芝刈りのしま模様と、うっすらハーフウェーラインとセンターサークル。斜めの辺に、対戦する2チームの色の線。左のチームの色が左側）が右から入り、つなぎ目で画面をおおって、左へ抜ける。まん中に横長のロゴ（logo.svg、影つき）
- 書き出し中の画面：しま模様の動くバー・のこり時間・プチ情報（6秒ごと）・「📵 終わるまで、この画面のままで」。保存の画面から作るハイライトは、書き出しているところを小さく映す。書き出し中に画面を離れたら、もどったときに知らせ、ページを閉じようとしたら確かめる

## 書き出しのカクつき（動画のコマごとに描いて録る）

撮った動画に・⚡ ハイライトの書き出しは、動画の1コマが出るたびに得点板などを描いて、その1コマを録る（requestVideoFrameCallback と captureStream(0)＋requestFrame。editor.js の startFrameSync）。前は画面の描き直しで描いて 30コマ／秒で録っていたので、コマが重なったり抜けたりしてカクついた（60コマ／秒の動画で、26コマ前後のばらばらな間隔 → ほぼ 60コマのまま）。

- 録りはじめにすぐ1コマ録る（重い動画で、最初のコマまで何も来ないと録画がうまく始まらないため）
- コマの合図が 0.2 秒来ないときは、画面の描き直しのタイミングで描いて録る（安全策）
- iPhone の Safari でもなめらか（2026-10-22 確認）。URL に `?framesync=0` を付けると、どのブラウザでも元のやり方（何かあったときの逃げ道）。使えない古いブラウザも元のやり方
- 書き出し中は、動画の枠を撮る画面の録画中と同じ赤い枠にし、左下に「● 書き出し中」。書き出し中のシートは、背景と見分けられるよう少し明るい色と白い縁
