# ろくが（RoQga）

スマホで試合を撮りながら、得点板（チーム名とスコア）を動画にそのまま入れて残すツール。名前は「録画」の「く」を Q にした、コネクト〜ConneQt〜の仲間（さくせん盤の追加アプリ）。アイコン・ロゴ・OGP は tools/icon.py で作る（おくるんの tools/brandkit.py を使う。さくせん盤と同じピッチの緑に、Q はカメラのレンズの輪と、真ん中に録画中の赤いランプ）。おくるんの一覧（line-share の data/hub-links.json の `key: "roqga"`）に載っている。はじめの画面のいちばん下に「📤 ろくがを紹介する」と仲間のアイコン列（line-share の shared/tool-share.js）。

公開URL: https://katsuan.github.io/score-recorder/

## できること

- チーム名・色を入れて「📹 カメラを開く」。はじめの値は、ろくがで前に使ったもの → さくせん盤で入れたチーム名・色（同じ katsuan.github.io の localStorage `soccer:state`）→ 空と紫・白
- チームは「左のチーム・右のチーム」と呼ぶ（自分のチームの試合とはかぎらないので）。2チームのあいだの「⇄」で左右を入れかえられる（後半にコートが変わったときなど。はじめの画面の並び・得点板・撮る画面の ＋1 の左右がそろって入れかわる）
- 「👀 プレビュー・GOAL のエフェクト」はたたんだ欄。開くと、動画に入る得点板のプレビュー（「プレビュー」の札つき（芝のピッチの絵に、チーム名・色・スコア、GOAL のエフェクト）。チームは得点板と同じ左右の並び
- GOAL のエフェクト：＋1 を押すと、画面の真ん中に得点したチームの色の帯と「⚽ GOAL!」、チーム名と新しいスコアを2秒ほど（動画にも入る。−1 で消える）。ふだんは「出さない」。たたんだ欄の中で「出す」にでき、「▶ 試す」でプレビューに出せる
- チーム名と色の組は保存できる： 名前・色・▼（保存したチームと、さくせん盤で入れた自チーム・相手から選ぶ）・保存／消す（いまの名前と色が保存済みなら「消す」）。自チーム・相手で同じ一覧。保存先は Q のサッカー系で共通の `q-soccer:teams`（あとでさくせん盤でも使えるように）
- 画面の回転をオフにしていても撮れる：縦の画面のときは「左に倒す／右に倒す」を選ぶと、撮る画面ごと 90° 回り、カメラの映像も横に回して描く（動画は横長）。録画中は向きを変えない。ほんとうに横向きになったら、ふつうの横向きにもどる
- 撮る画面はスマホを横向きで使う。下のまんなかの赤い丸で録画の開始・停止。そのすぐ左が左のチーム、右が右のチームの「＋1」（下の小さな「−1」で取り消し。画面のはしではなく、まんなかからの距離で置くので、画面の長さがちがう端末でも同じ場所）。＋1 はチームの色のボタン（字は色の明るさで白か黒）。右上の「◀ 左よせ・まんなか・右よせ ▶」で、片手で持つ側に寄せられる：寄せると ＋1 が縦に2段（上が得点板の左のチーム。色で見分ける）、−1 はその内側、録画ボタンは反対側のはしへ（録画中も切りかえられ、選んだ位置は端末に残る）。録画ボタンはタップで開始・停止。録画中の時間は上のまんなか。「← 戻る」と「⇅」（倒して撮るときだけ。倒す向きを逆にする）は右上（倒して撮るときは、スマホの上のはしの側。録画中は隠す）
- 得点板は映像の左上に「[色] 左のチーム 2 - 1 右のチーム [色]」（チーム名がないときは、名前の代わりにチームの色の丸）。時間は入れない（動画の時間を見る）
- LINE で送れる動画は5分まで：いつも5分（4分55秒）ごとに自動で次の1本に分けて録る（MediaRecorder を新しくする。あとから動画を切るのはブラウザでは難しいため）。5分以下なら1本だけ。5分を超えたときだけ、止めたあとの保存の画面で「全部（5分ごと）・最初の5分・最後の5分（最後の1本）」から残すものを選べる。確かめるときは ?segment=秒 で区切りを短くできる
- 止めると見返し・保存（iPhone などは共有メニューから「ビデオを保存」、それ以外はダウンロード）。動画はこの端末にだけ残り、サーバーには送らない
- ＋1／−1 を押すと、押したボタンが一瞬光る（Android は軽く震える）。画面のまんなかには何も出さない（動画に入るのか迷わせないため。いまの点は、動画に入る左上の得点板で見える）。押しまちがいは、そのチームの −1 で直す（画面がごちゃつかないよう「取り消す」ボタンは出さない）
- 録画中は画面のふちが赤く光る（撮れているか、ひと目で分かる。動画には入らない）
- はじめの画面の「📹 カメラを開く」は画面の下に固定（スクロールしなくても押せる）
- 保存の画面に、保存のしかたの案内（iPhone は「📤 保存・共有」→「ビデオを保存」で写真へ。共有できない端末は ⬇️）
- はじめの画面の上のタブで「📹 撮る」と「🎞 あとから付ける」を切りかえる（チーム・色・プレビュー・スコアは共通）
- あとから付ける：「🎞 動画を選ぶ」で端末の動画を選ぶ → 動画を流しながら、点が入ったところでチームの色の ＋1（まちがえたら −1 か一覧の ✕。一覧の時間を押すと、その少し前へ）→「📼 得点板つきで書き出す」。書き出しは動画を最初から流して、得点板（GOAL のエフェクトを出す設定ならそれも）つきの絵と動画の音を録る（ブラウザでは動画と同じ時間かかる。5分ごとに分けるのも、保存の画面も撮るときと同じ）。動画が途中からなら、はじめの画面の「スコアを変える」で、はじめのスコアを入れておく。長さの入っていない webm（Android のろくがの動画など）も、いちど最後まで飛ばして長さを調べてから使う
- 保存の画面のいちばん下は「次はどうする？」の3つ：「▶ 続きを撮る」（同じチーム・いまのスコアのまま。後半など）、「⟲ 同じチームで 0 - 0 から」（次の試合）、「🏠 はじめの画面へ」（チーム・色を変える）。共有がすんだら「✓ 共有できました」と出て、0 - 0 からの方が目立つ。どれを選んでも動画は消えず、保存の画面に「1回目・2回目…」と並ぶ（保存・共有したものには ✓）。消すのは動画の行の 🗑（まだ保存していないものだけ確かめる）。ページを閉じる・更新すると動画は消える（案内にも書く）。はじめの画面にもどっても、録った動画があれば「🎞 録った動画（◯本）」から開ける
- スコアは端末に残る（`roqga:state`）。はじめの画面ではチーム名のあいだに、いまのスコア（左右の並びに合わせる）。「✏️ スコアを変える」かスコアを押すと、各チームの下に − ＋ が出て、試合の途中から撮るときにいまの点を入れておける。点があるときは「0 - 0 にする」

## しくみ

カメラの映像と得点板を1つのキャンバスに描き、そのキャンバス（＋マイクの音）を MediaRecorder で録る。ボタンはキャンバスの上に重ねた別の部品なので、動画には入らない。録れる形式は端末による（iPhone は mp4、Android・パソコンは webm のことが多い）。撮っている間は画面を消さない（Wake Lock）。

注意：録画中に画面を消したり別のアプリに切りかえたりすると、映像が止まる。長く撮ると発熱・電池の消耗が大きいので、前半・後半で分けて撮るのがよい。
